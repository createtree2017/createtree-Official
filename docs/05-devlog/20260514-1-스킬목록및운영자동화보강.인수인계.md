# 스킬 목록 및 운영 자동화 보강 인수인계

## 변경 파일

- `.agents/scripts/generate_skills_index.py`
- `.agents/scripts/validate_skills.py`
- `.agents/skills/SKILLS_INDEX.md`
- `AGENTS.md`
- `package.json`

## 핵심 변경 내용

- 기존 `.agents/skills/` 설치본은 삭제하지 않고 유지했다.
- 설치된 15개 스킬을 `.agents/skills/SKILLS_INDEX.md`에 자동 정리했다.
- `npm run skills:sync`, `npm run skills:check` 명령을 추가했다.
- `npm run verify`에 스킬 검증을 포함했다.
- `AGENTS.md`에 Skill Impact Check, 사용자 확인이 필요한 운영 정책 변경 기준, 스킬 목록 자동 갱신 규칙을 추가했다.
- 기존 `composition-patterns` 스킬의 multiline frontmatter description을 읽을 수 있도록 자동화 스크립트를 보강했다.

## 왜 변경했는지

CT_official은 이미 스킬 구성이 잘 잡혀 있었지만, 스킬 추가/삭제/수정 시 한눈에 보는 목록과 최신성 검증이 없었다. 병원 랜딩페이지는 의료광고, 개인정보, 상담 리드, SEO, Railway 운영 기준이 중요하므로 스킬 목록과 자동 검증을 운영 흐름에 포함했다.

## 검증 결과

- `npm run skills:sync`: 통과
- `npm run skills:check`: 통과
- `npm run verify`: 통과

## 주의사항

- `SKILLS_INDEX.md`는 직접 수정하지 말고 `npm run skills:sync`로 재생성한다.
- 기능 개발, 기존 기능 변경, 업데이트 완료 시 Skill Impact Check를 수행한다.
- 의료광고/개인정보/DB/배포/AI provider/금전/자동화 권한 정책 변경은 사용자 확인 후 스킬에 반영한다.
- git add, commit, push는 수행하지 않았다.

## 추가 보강

- 컨텍스트와 개발 속도 보호를 위해 자동 호출 범위를 `$createtree-landing-polish`로 제한했다.
- 나머지 공통 품질/참고 스킬은 설치 상태를 유지하되 `$스킬명`으로 명시 호출할 때만 사용하도록 `allow_implicit_invocation: false`로 변경했다.
- `npm run skills:sync`와 `npm run skills:check` 재검증을 통과했다.
